#FX Navigator

## Personal Investment Dashboard

FX Navigator is a web application for monitoring:

- Exchange rates
- Macroeconomic events
- Central bank decisions
- Oil market
- US stocks
- Personal investment portfolio
- AI-powered daily market analysis
